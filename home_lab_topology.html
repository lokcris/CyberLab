Architecture notes

  • Host runs Oracle VirtualBox as the sole hypervisor for all four guests.
  • Attacker and victims share one internal-only network — no NAT, no bridged adapter.
  • Victim VMs and the Wazuh manager carry a second, host-only adapter dedicated to agent-to-manager traffic.
  • The physical host runs its own Wazuh agent, reporting over that same host-only link — kept apart from Kali's segment.
